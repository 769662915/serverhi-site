# Research: Docker Container Has No Internet — A Systematic Troubleshooting Guide

## Sources
1. Baeldung - "How to Fix if Docker Container Has No Internet"
   - Common causes: DNS misconfiguration, iptables/firewall rules, IP forwarding disabled, outdated Docker networking
   - DNS fix: use --dns 8.8.8.8 or configure globally in /etc/docker/daemon.json
   - If ping to IP works but nslookup fails → DNS issue
   - If both fail → lower in the stack (routing, firewall, IP forwarding)

2. Netdata - "Docker container cannot connect to the internet"
   - Step 1: Determine if failure is DNS or IP (ping IP vs nslookup)
   - Step 2: Check which network container uses (docker inspect)
   - User-defined networks: DNS via Docker embedded resolver at 127.0.0.11
   - Default bridge: Docker copies host's /etc/resolv.conf
   - Fixes: DNS misconfiguration, iptables/firewall conflict, IP forwarding disabled

## Key Facts
- Most common cause: DNS misconfiguration inside the container
- Diagnostic flow: ping IP → nslookup → check resolv.conf → check docker network → check iptables → check IP forwarding
- User-defined networks use Docker's embedded DNS resolver (127.0.0.11)
- Default bridge network copies host's /etc/resolv.conf
- IP forwarding must be enabled for containers to reach external networks
- iptables/firewall rules can break Docker's NAT and forwarding
